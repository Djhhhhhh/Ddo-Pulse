# HTML 截图功能修复 测试计划

> 基于已确认的 spec.md 生成的验收测试 checklist。

---

## G1. 幻灯片截图完整性

- [ ] human: 生成一份包含多页内容的 HTML 报告（内容高度超过 800px），检查每页截图是否完整显示所有文本内容，无截断
- [ ] human: 对比 HTML 页面和截图，确认截图中的标题、摘要、深度分析、关键点等内容与页面一致
- [ ] human: 检查截图中的排版布局是否与 HTML 页面保持一致，无错位或变形

通过标准：所有幻灯片截图完整捕获页面内容，无截断、无缺失、布局一致。

---

## G2. 头条封面图

- [ ] human: 检查生成的 `cover-main.png` 文件是否存在
- [ ] human: 检查 `cover-main.png` 的尺寸是否为 900 × 383 像素
- [ ] human: 检查封面图内容是否来自 HTML 首页（第一张幻灯片）
- [ ] human: 确认封面图在公众号编辑器中预览效果正常，核心内容在安全区内

通过标准：头条封面图尺寸正确（900×383），内容清晰，符合公众号规范。

---

## G3. 次条封面图

- [ ] human: 检查生成的 `cover-sub.png` 文件是否存在
- [ ] human: 检查 `cover-sub.png` 的尺寸是否为 200 × 200 像素
- [ ] human: 检查封面图内容是否来自 HTML 首页（第一张幻灯片）
- [ ] human: 确认封面图在公众号编辑器中预览效果正常

通过标准：次条封面图尺寸正确（200×200），内容清晰，符合公众号规范。

---

## G4. 错误处理

- [ ] human: 当 HTML 文件不存在时，确认程序记录警告并返回空列表，不崩溃
- [ ] human: 当 Playwright 未安装时，确认程序记录警告并返回空列表，不崩溃

通过标准：异常情况下程序优雅降级，记录日志，不抛出未捕获异常。
