# Task 03: 测试验证

## 任务描述

运行报告生成流程，验证截图功能修复效果。

## 关联验收点

- G1: 幻灯片截图完整性
- G2: 头条封面图
- G3: 次条封面图
- G4: 错误处理

## 测试步骤

### 1. 生成测试报告

运行报告生成流程，生成包含多页内容的 HTML 报告。

### 2. 检查幻灯片截图

- 确认每页截图完整显示所有内容
- 对比 HTML 和截图内容一致性
- 确认排版布局无错位

### 3. 检查封面图

- 确认 `cover-main.png` 存在且尺寸为 900×383
- 确认 `cover-sub.png` 存在且尺寸为 200×200
- 确认封面图内容来自 HTML 首页

### 4. 检查错误处理

- 测试 HTML 文件不存在时的降级处理
- 测试 Playwright 未安装时的降级处理

## 输出产物

- 测试通过的截图文件
- 测试报告
