# Backend M1 — SQLite + CLI 源管理 + RSS 抓取 + run-once

## 背景与目标

Ddo-Pulse 后端首期需打通「配置 → 抓取 → 落库」最小闭环。用户通过 CLI 初始化 `~/.ddo_pulse`、添加 RSS/JSON Feed 订阅源，执行 `run-once` 将文章元数据写入 `raw_items`。本阶段不调用 LLM、不推送飞书。

## 需求概述

1. `ddo-pulse init`：创建数据目录、默认 `config.yaml`、初始化 SQLite（全表 schema）。
2. `ddo-pulse source add|list|rm|enable|disable`：管理 `sources` 表。
3. `ddo-pulse config show|import|export`：YAML 与 DB 同步（M1 实现 import/export 基础）。
4. `ddo-pulse run-once`：对 enabled 源执行抓取，upsert `raw_items`（URL 唯一）。
5. 支持源类型：`rss`、`json_feed`（feedparser）。

## 技术方案

### 方案选型

- **语言**：Python 3.11+
- **数据库**：sqlite3 标准库，路径 `Path.home() / ".ddo_pulse" / "ddo_pulse.db"`
- **CLI**：typer
- **抓取**：feedparser + httpx（User-Agent、超时）
- **配置**：PyYAML 读写 `config.yaml`；业务配置以 SQLite 为权威
- **设计**：fetcher 适配器 + pipeline 编排；repository 封装 SQL

### 核心实现步骤

1. **db**：`schema.sql` 落实 mvp §11 全表；`Database` 类 init/migrate、sources/raw_items CRUD。
2. **paths**：`get_data_dir()`、`get_db_path()`、`get_config_path()` 统一跨平台。
3. **config**：默认 yaml 模板；`config import` 将 yaml 中 sources 写入 DB。
4. **fetchers**：`RawItem` 模型；`normalize_url`；`RssFetcher` 处理 rss/json_feed。
5. **pipeline**：`run_once(db)` 遍历 enabled sources → fetch → insert ignore duplicate url。
6. **CLI**：typer 子命令挂载；退出码非 0 表示失败。

## CLI 命令

| 命令 | 说明 |
|------|------|
| `ddo-pulse init [--force]` | 创建目录、config.yaml、初始化 DB |
| `ddo-pulse source add NAME TYPE URL [--config-json JSON]` | 添加源 |
| `ddo-pulse source list` | 列表 |
| `ddo-pulse source rm ID` | 删除 |
| `ddo-pulse source enable ID` / `disable ID` | 启用/禁用 |
| `ddo-pulse config show` | 打印数据目录与源数量（脱敏） |
| `ddo-pulse config import` | 从 yaml 导入 sources |
| `ddo-pulse config export` | 导出 yaml |
| `ddo-pulse run-once` | 执行抓取流水线 |
